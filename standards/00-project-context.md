## 1. 项目是什么

- **项目名称**:`banksys`
- **一句话目标**:`基于银行营销数据构建一个既能做交互式数据分析、又能在线预测客户是否会认购产品的教学项目。`
- **使用者/受益者**:`课程学生、项目开发者、需要查看营销数据并进行认购预测的业务使用者。`
- **核心功能**:
  - `数据分析交互页面:展示银行营销数据的分布、对比和关键洞察。`
  - `离线训练 + 在线预测系统:基于训练数据离线产出模型,并在页面中通过点选式输入返回是否认购的预测结果。`
- **输入/数据**(如有):`数据来自项目内的银行营销数据集,data/train.csv 含训练标签 subscribe,data/test.csv 为待预测样本。属于结构化表格数据,当前样例规模为万级记录;默认作为教学数据随项目管理,但训练产物、缓存文件和大体积中间文件默认不进 Git。`

## 2. 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 语言/运行时 | `Python 3.11` | 数据处理、建模与 Web 原型开发生态成熟,与课程目标匹配 |
| Web/API 框架 | `streamlit` | 适合快速构建数据分析界面和点选式预测交互页面 |
| 测试 | `pytest` | Python 生态主流测试工具,便于覆盖数据处理、训练和预测逻辑 |
| 格式/静态检查 | `ruff` | 同时覆盖格式化与静态检查,配置简单,适合教学项目 CI |
| 打包/运行 | `Docker` | 保证本地、CI、部署环境一致,便于后续 CD 自动部署 |
| CI/CD | GitHub Actions | 通用、可视化、适合教学与团队协作 |

## 5. 不变约束

- 密钥、密码、私钥、Token **绝不写进代码或文档**,只进 GitHub Secrets / 环境变量。
- `data/train.csv`、`data/test.csv` 作为教学数据可进 Git;训练生成的模型文件、缓存文件、临时导出文件默认不进 Git。
- `main` 分支受保护,日常开发必须走 feature 分支 + PR。
- CI 红灯不合并。
- Streamlit 服务端口固定采用 `8004`。
- 项目目标是跑通完整 `CI + CD`,因此必须同时覆盖代码质量检查、测试、镜像构建、自动部署与部署后验证。
